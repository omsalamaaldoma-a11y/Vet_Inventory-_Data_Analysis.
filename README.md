Veterinary Inventory Dashboard (Power BI)
📊 Project Overview
This is a Power BI portfolio project designed to analyze veterinary inventory performance using simulated (dummy) data.
The dashboard focuses on tracking stock levels, expiry risks, and key inventory KPIs to support data-driven decision making for veterinary pharmacies and clinics.
🛠 Tools Used
Power BI
Power Query
DAX
Excel (for data simulation)
📈 Key KPIs
Total Stock Quantity
Inventory Value
Fast vs Slow Moving Items
Expiry Risk Items
Out-of-Stock Products
📊 Dashboard Features
Interactive inventory overview
Product category and supplier analysis
Expiry date monitoring
Drill-through buttons from insights to action pages
Interactive filters and slicers
📁 Data Source
Simulated (dummy) data created for portfolio and learning purposes only.
🎯 Business Questions Answered
Which products have high expiry risk?
Which items are overstocked or understocked?
How does inventory value change by category?
Which products require urgent action or replenishment?
